# Telegram-бот: время, погода, биткоин, новости, задачи

Бот на Python (только стандартная библиотека, без сторонних пакетов).
На любое сообщение отвечает временем в Астане, погодой и курсом биткоина.

## Какие API использованы

| API | Для чего | Какие запросы | Ключ |
|---|---|---|---|
| [Telegram Bot API](https://core.telegram.org/bots/api) | приём и отправка сообщений | `getMe`, `deleteWebhook` (с `drop_pending_updates`), `getUpdates` (long polling, `offset`, `allowed_updates`), `sendMessage` | токен бота от @BotFather |
| [Open-Meteo](https://open-meteo.com/en/docs) | текущая погода в Астане | `GET /v1/forecast` (`temperature_2m`, `apparent_temperature`, `relative_humidity_2m`, `pressure_msl`, `wind_speed_10m`, `weather_code`) | не нужен |
| [CoinGecko](https://docs.coingecko.com/reference/simple-price) | курс биткоина в USD и KZT, изменение за 24 ч | `GET /api/v3/simple/price` | не нужен (у бесплатного доступа есть лимит запросов) |

Не API, но тоже внешние источники и интеграции:

- **Веб-превью публичного канала** `https://t.me/s/zakonkz`. Бот разбирает HTML и берёт последний пост с текстом (ответ на «что нового»). Это не официальный API, при смене вёрстки Telegram разбор может сломаться.
- **Локальная синхронизация с «Планером задач».** Бот поднимает HTTP-сервер на `127.0.0.1:8765` (эндпоинт `POST /tasks`), планер (страница `index.html` из отдельного проекта) отправляет на него список задач. Доступно только с этого компьютера, чужие сайты отсекаются проверкой `Origin`.

## Что умеет бот

- любое сообщение: время, погода, курс биткоина (владельцу ещё и открытые задачи);
- сообщение со словом «привет»: вместо погоды текст из `privet.txt`;
- сообщение «что нового»: последняя новость из канала @zakonkz;
- `/id`: показывает chat id (нужен для `OWNER_ID`);
- сообщения, пришедшие, пока бот был выключен, игнорируются.

## Запуск

1. Создайте бота у @BotFather и получите токен.
2. Создайте файл `.env` рядом с `bot.py`:

   ```
   BOT_TOKEN=токен_от_BotFather
   OWNER_ID=ваш_chat_id
   ```

   `OWNER_ID` можно узнать, написав боту `/id`. Без него задачи из планера никому не показываются.
3. По желанию создайте `privet.txt` с текстом ответа на «привет» (без файла бот ответит «Привет!»).
4. Запустите:

   ```
   python bot.py
   ```

`.env`, `tasks.json` и `privet.txt` не попадают в git (см. `.gitignore`).
